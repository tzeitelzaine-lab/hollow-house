# Host guide — Who Unalived the CEO of BlueGreen Insurance?

> **Contains the full solution.** Keep this document and the host dashboard off any shared screen.

## Before the event

1. Complete the README setup and create your event.
2. Play the case once in **preview mode** (host dashboard → Open preview mode). With the answers below it takes about 10 minutes.
3. Optional: add your own clues under **Extra evidence**.
4. Reset or recreate the event so rehearsal results are cleared.

## The solution

**Amanda Sterling** (mastermind) commissioned the killing. **Marigold** (clinical accomplice) carried it out. GCH-X41 was disguised as GCH-U17 behind a falsified urgent order. Amanda's motive was to keep Albert's expected control and prevent Allison opening the charity books she managed.

| Person | Finding |
| --- | --- |
| Amanda | Mastermind. Did not know the signed recommendation already existed. |
| Marigold | Overheard the decision, messaged Amanda, altered the record, handled the package, framed Mario and Matthew. |
| Allison | Initial prime suspect, falsely accused. Wanted the job; did not poison anyone. |
| Mario | Administered unwittingly. Not clarifying the conflicting order is a practice concern, not murder. |
| Matthew | Falsely named second checker; in room 710 from 20:34 to 20:43. |
| Agatha | Leaked the meeting for a VP bargain; Andrew's secret lover. Not involved in the killing. |
| Albert | Accepted the tip and the bargain. No knowledge of the killing. |
| Dr Veil | His name on the record proves nothing. Not involved. |
| Dr Brown | Provisional "possible toxic exposure" was good medicine. Not involved. |

### Two events

- **Morning:** stress cardiomyopathy complicated by VF. Andrew drank at 09:15, before Allison arrived at 09:18. The drink held no tested toxicant. Pulse returned at 09:35.
- **Evening:** GCH-X41 exposure at 20:40. Arrhythmia at 20:44. Death at 21:06.
